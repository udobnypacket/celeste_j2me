Celeste Classic -> J2ME (Nokia 6303i, MIDP 2.0 / CLDC 1.1), без звука.

Файлы:
  src/CelesteMIDlet.java  - вход
  src/Game.java           - вся игра (логика = 1:1 порт Lua, отрисовка 128->240 px, тайл 15x15)
  res/data.bin            - спрайты (4096) + карта 128x64 (8192) + флаги (128), вытащены из картриджа
  build.sh                - сборка (javac -> preverify -> jar + jad)

Управление: крестовина или 2/4/6/8 - движение, 1 или 7 - прыжок, 3/9/5 - рывок, правая софт-клавиша - выход.
